# MelodyMate

从一个生活声音开始，选取片段、试听两个编排方向、亲手调整节奏，再导出四小节音乐。AI 只提出可试听、可采纳的参数建议，作品由用户决定。

当前状态：`npm run check`（51 项测试与类型检查）和生产构建通过。已在 Codex 内置浏览器验证本地预置创作流程，并确认一份 WAV 实际下载、格式与时长正确；连续下载、桌面 Chrome、有效音频文件导入、真实麦克风、TokenHub 联调与听感仍待验证。详见 [MVP 验收记录](./docs/MVP验收记录.md)。

## 本地启动

需要 Node.js 24 或更高版本和 npm。应用面向桌面 Chrome，录音需要本机回环地址或 HTTPS。

1. 在项目目录执行 `npm ci`，按锁文件安装依赖。
2. 将 `.env.example` 复制为本机 `.env.local`，按下表填写。真实密钥只放 `.env.local`，不要提交到 Git、粘贴到页面或写入日志。
3. 执行 `npm run dev`，打开 `http://127.0.0.1:3000`。

| 配置 | 用途 |
|---|---|
| `APP_ORIGIN` | 浏览器访问的完整来源，默认 `http://127.0.0.1:3000`；协议、主机与端口必须一致，不加路径或尾斜杠。`localhost` 与 `127.0.0.1` 不等价。 |
| `DEMO_ACCESS_TOKEN` | 自行设置的独立演示口令；服务端未配置时拒绝 API 请求。不能复用模型密钥。 |
| `MODEL_API_URL` | 完整聊天接口 URL；TokenHub 示例为 `https://tokenhub.tencentmaas.com/v1/chat/completions`。 |
| `MODEL_API_KEY` | 服务端模型密钥，以 Bearer 认证发送；不要使用 `NEXT_PUBLIC_` 前缀。 |
| `MODEL_NAME` | 当前账号实际已开通的模型 ID。 |
| `TRUST_PROXY` | 默认 `false`，所有来源共享限频；只有受控代理会覆盖 `X-Real-IP` 时才设为 `true`。 |

页面“创作设置”中的演示口令留在当前页面内存。模型密钥不能填入此处。不配置模型也可使用本地预置方向和手动编辑；预置结果会明确标注，文字修改功能需要真实模型连接。

常用检查与启动脚本：

```bash
npm test
npm run typecheck
npm run check
npm run build
npm run dev
```

`npm run check` 依次执行测试和类型检查。生产模式本机验证先运行 `npm run build`，成功后运行 `npm run start`。启动与构建的验证状态见验收记录。

## 演示流程

页面顶部提供“选声音 → 排节奏 → 找感觉 → 导出”的四步路线，第一次可以点“用玻璃示例开始”。各区域的问号卡片默认收起，展开后说明它在音乐中的作用和一个操作例子；“有想要的感觉，但不知道怎么调？”提供松弛、跳跃、温柔三种手动调整起点。当前制作的是 8～12 秒音乐小品，不是带歌词与演唱的完整歌曲。

1. 点“用玻璃示例开始”，或载入其他合成示例，明确说明这是本地合成的模拟声音。
2. 试听原始片段，拖动波形选区或微调边界，选择 50～500 ms 的片段。
3. 点“生成两个方向”，分别点“试听这个方向”，再“采纳这个方向”；候选试听不改变当前作品。未连接模型时展示本地预置方向。想法示例按钮只填写文本与调整范围，用户点击发送后才发起建议请求。
4. 手动修改节奏格、速度或原声音量，再撤销一次，检查作品恢复。
5. 在原声清晰时允许和弦伴奏，选择预置方案，比较原声、伴奏与完整作品；开启许可本身不会自动加入伴奏。
6. 导出当前已采纳作品的 WAV，并检查下载目录中的文件；如自动下载没有开始，点击播放器右侧的“保存上次导出”。该链接保存最近一次导出快照，修改作品后需要重新导出。刷新前保存文件；连续下载的落盘行为仍待跨浏览器复验。

真实录音与真实 TokenHub 建议另行验证，不用模拟示例或本地预置结果代替。首次接入 TokenHub 前，在平台为专用密钥设置模型访问范围和每日 Token 限额；本项目不会自动配置这些限制，也未验证目标账号的实际配置。

## 技术与数据边界

- 单个声音文件最多 10 秒、10 MiB，优先验证 WAV/MP3；录音约 2 秒。没有视频抽音、转码或多素材时间线，不承诺所有编码与手机 Safari 兼容。
- 浏览器保留并处理原始音频；服务端仅接收文字、工程参数及轻量声学指标。这些指标也属于用户数据，不能将产品描述为完全离线。
- 模型没有听到音频，不识别声源物体、音高或调性，不生成整首音频，只返回白名单参数建议。两套和弦是规则合成的预置方案。
- 固定 4/4 拍、四小节、16 格底稿；80/100/120 BPM 对应 12/9.6/8 秒。导出为单声道 44.1 kHz、16-bit PCM WAV，不包含可重新编辑的工程。
- 原声预增益最多 6 倍，不是降噪或感知响度归一化。近乎无声的片段需重新选择或录制后才能制作、导出；原声太轻时禁用伴奏。
- 仅当前页面内存保存工程，支持最近五次撤销；换素材清空历史，没有重做、数据库、自动保存或分享。刷新、关闭页面会丢失工程。
- 唯一业务 API 为 `POST /api/suggest`，校验来源、演示口令、实际请求体大小和编辑范围。模型调用非流式，10 秒超时、最多 1024 输出 Token，不自动重试；失败时仅探索可降级为明确标注的预置方向。
- 每来源每分钟 10 次请求、最多 2 路在途调用，均为单个 Node 进程内保护，重启会清零。SCF 等多实例部署需另配并验证网关或共享原子计数，不能声称已有全局限流。
- 默认范围为本机或单进程封闭演示，尚未验证部署。每日 Token 限额不是人民币硬预算，也不覆盖云函数等资源费用。
