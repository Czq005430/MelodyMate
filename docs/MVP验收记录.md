## 已知范围边界

- 示例玻璃、木头、沙沙声均为本地合成的模拟声音；不能作为真实录音成功的证据。本地预置建议也不能作为真实 AI 调用成功的证据。
- 无视频抽音、多素材、自由和声生成、工程持久化或分享；刷新会丢失工程，WAV 仅为成品音频。
- 原声留在浏览器；文本、工程参数与轻量声学指标会随模型建议请求离开设备。模型不直接听音频。
- 默认伴奏关闭，用户允许后才能加入规则合成预置和弦。近乎无声不能制作或导出；较轻原声只能制作纯原声作品。
- 限频与并发保护只作用于单个 Node 进程，重启清零；多实例全局保护及平台每日限额均不能从本地测试推定。
- 当前未作真实 TokenHub 调用、真实麦克风验收或云端部署验收；每日 Token 限额不等于全部云资源的人民币硬预算。
