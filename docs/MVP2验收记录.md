## 关键修复

- 当前宿主有 `document.modelContext.registerTool`，没有 `unregisterTool`。无注销接口时每个文档仅注册一次，调用转发到当前有效工作台；卸载后拒绝调用，重挂载不会重复注册。支持注销的环境仍使用正常清理流程。
- 录音锁与播放停止分离；新提案、放弃提案、修改工程会使旧试听失效。导入/导出均用请求序号拦截旧结果，旧任务不能清除新任务状态。工程改变后旧下载链接撤销。
- 6 倍有限增益后仍过轻的素材提示靠近麦克风重录；明显双击不伪称可靠对齐，短窗持续音不能冒充清晰敲击。

## 未验收与限制

- **真实麦克风、现场偏拍录制与人工音质判断尚未验收。** 未擅自授予麦克风权限；算法测试与合成示例不能证明真实设备延迟、底噪、音色和音乐效果。
- 未验证独立桌面 Chrome、手机 Safari、全部上传格式或连续下载跨浏览器行为。页面工具可用性取决于 Codex 宿主；不可用时可用交接卡，本地规则初稿仍可编辑导出。
- 每段单独渲染不包含前段延续尾音，并独立执行峰值保护，因此不承诺逐样本等同整曲切片。单段用于快速听配器，最终以整曲导出为准。
- 钢琴为三个根音采样移调，低音与铺底为合成；没有专业音源、多力度采样、歌词或人声生成。明确音高的生活声音可能与和弦冲突。
- Codex 在当前对话中理解文字并提出参数，未直接听取原录音。网页不是独立聊天机器人，不能把订阅当作公开网站 API 配额。
- 工程仅内存保存；WAV 不含可恢复工程。完整资料与演示步骤见 [README](../README.md)；素材署名见 [SOURCES.md](../public/audio/piano/SOURCES.md)。
